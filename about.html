这是什么

一个完全静态的资讯聚合站：GitHub Actions 每天定时抓取各路 RSS / Atom 源， 按分类聚合后生成 data/news.json，前端直接读取渲染。 没有后端、没有数据库、没有 Jekyll / Ruby 依赖。

怎么改关注方向

所有关注方向都在 config/feeds.yaml 里定义，改完提交即可，前端会自动适配新的分类与配色：

  • 加/删分类：改 categories 列表（id、name、color）
  • 加/删资讯源：改对应分类下的 feeds（RSS / Atom 地址）
  • 临时停用某个源：给它加一行 disabled: true
  • 只想要某类内容：给分类或源配 keywords，命中标题/摘要才保留
  • 首页保留天数、每源条数：改 settings.retention_days、max_items_per_feed

本地预览

pip install -r scripts/requirements.txt
python3 scripts/fetch_news.py        # 抓取并生成 data/news.json
python3 -m http.server 8000          # 访问 http://localhost:8000

AI 一句话摘要（可选）

在仓库 Settings → Secrets 中配置 OPENAI_API_KEY（或 DeepSeek / Moonshot 等兼容接口， 另配 OPENAI_BASE_URL、OPENAI_MODEL 变量），或配置 ANTHROPIC_API_KEY。 工作流会自动为最新资讯生成中文一句话摘要；未配置任何 Key 时该步骤自动跳过，站点照常运行。
